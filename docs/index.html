DELPHI event display

DELPHI events straight from edm4hep — no DELGRA, no X11, no ROOT. Drawn with Plotly, and it runs in your browser.

Open the event display → A showcase event loads immediately; drop your own .edm4hep.root file to explore any event. Documentation → Install, command line, collections and roles, what is drawn, the decoding rules, Python API.
Try the new Poynting energy-flow views. Open the synthetic two-jet demo, then choose Poynting and switch between the 2-D projected sphere and 3-D sphere. This hand-built illustration is not DELPHI collision data or a physics simulation. The real-data showcase remains separate.

What it does

Opens any DELPHI edm4hep file, in the browser. Drop a file on the display and uproot reads it locally under Pyodide — nothing is uploaded, and there is no server behind this page.

Nothing is pinned by collection name. A DELPHI file holds 3 Track collections, 7 Vertex, 4 Cluster, 2 TrackerHit3D and 24 ParticleID. The display discovers them from podio's own metadata and binds each part of the picture to one by role, which you can change. Beside the figure, every collection is listed with its type, domain, provenance, links and per-event count; select one and everything not from it dims, or click a track to select its collection.

Only measured quantities are drawn. Tracks are helices from their own perigee parameters, started at the vertex they belong to, with the back-extrapolation to the IP dotted so the picture never claims a path the particle did not travel.

In the 3-D scene this matters more, not less: a vertex-detector hit is a strip, so it constrains a line in space, not a point. Hits on a track are placed at the z their own track measures; hits on no track are drawn as the line they actually constrain.

Four panels, or the detector

  • (a) r-φ whole event — helices, EM showers as towers, the HPC radius taken from the shower positions
  • (b) r-z — the same tracks, r signed by thrust hemisphere
  • (c) vertex detector — VD layers, R-φ hits, primary and secondary vertices; zoom replaces the fixed inset
  • (d) RICH — Cherenkov angle against momentum, liquid and gas radiators, with π/K/p curves and veto markers
  • 3-D — the barrels, the helices in space, showers and vertices, physically proportional
  • Poynting — a 2-D projected sphere or a 3-D direction sphere, with energy/momentum weights
